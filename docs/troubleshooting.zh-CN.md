# 故障排查（中文）

| 症状 | 处理 |
| --- | --- |
| `429 Too Many Requests` | 等待退避，复用 cache，降低批次频率；不要并行重跑整本书。 |
| `ILLEGAL_ACCESS` | 检查会话/设备配置和请求频率；不要把错误 JSON 写入章节缓存。 |
| `empty response` | 检查本地服务、运行时资源和上游状态，只重试缺失批次。 |
| 标题不一致 | 目录标题是权威值；删除疑似错误批次并重新获取。 |
| EPUB CRC/mimetype 错误 | 重新生成 EPUB，确认传输工具没有改写 ZIP。 |
| 服务器重复导入 | 以标题查最终书架/数据库状态；删除暂存副本并保持 manifest 与 EPUB 同目录。 |
